# AI 脱敏固定评测集

本目录只保存虚构、脱敏且可进入 Git 的样本，不得复制真实简历、联系人、聊天、截图、录音或转写全文。

当前离线基线覆盖：多岗位材料、提示词注入文字、相对投递日期、日期冲突、缺少投递日期、长录音稳定分段，以及结构化结果的额外字段、错误分类和损坏数组。它用于验证确定性规则与合约，不调用外部模型，因此可以在每次改提示词前后重复运行。

需要比较模型或提示词质量时，使用相同 fixture 逐项记录：目标岗位判断、字段准确率、证据正确率、日期状态、格式成功率、无依据内容数、耗时和 token。模型输出只保存在本地临时目录，人工核对后只提交汇总指标；不得把原始服务商响应或真实求职材料加入仓库。
