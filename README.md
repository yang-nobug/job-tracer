# job-tracer

一款本地运行的求职管理工具，用来记录投递、跟进面试、整理面经、准备面试，并集中处理招聘邮件中的笔试、测评和面试通知。

服务只在本机 `http://localhost:3210` 运行，不会主动把你的求职数据上传到其他服务器。

## 主要功能

- **投递管理**：用看板、列表和统计查看每一条投递的状态、渠道、地点、JD、投递进度链接和动态记录。
- **智能录入**：粘贴招聘文字或上传截图，由 AI 提取公司、岗位、地点、JD、投递时间等信息；保存前可以逐项核对和修改。
- **面试与复盘**：为投递添加面试安排、准备清单和复盘记录，持续跟踪每一轮进展。
- **面经知识库**：录入文字或截图面经，自动拆分题目；可编辑题目和答案、生成或重新生成答案、恢复旧答案，并导出为 Markdown。
- **AI 面试准备**：根据岗位 JD、历史面经、复盘、简历和项目档案生成准备计划、学习模块、练习与陪练内容。
- **简历与项目档案**：保存不同简历版本，提取 PDF/DOCX 文字；接入本机项目目录后，可让代码阅读能力为面试准备提供项目事实。
- **招聘邮箱与日程**：连接 QQ 邮箱或 163 邮箱，扫描招聘邮件；AI 识别并复核明确的笔试、测评、面试等通知后，自动写入日程。
- **飞书分享**：把岗位信息发送到飞书群，群消息可直接复制并粘贴回智能录入。

## 快速开始

1. 安装 Node.js 24.x。
2. 双击 `start.bat`。
3. 浏览器打开 <http://localhost:3210>。

如果需要使用 AI 面试准备，再安装 Python 3.11 或 3.12；启动脚本会自动创建所需环境。

## 配置 AI

AI 功能是可选的。不配置时，投递记录、面试、复盘、知识库和手动录入都可以正常使用。

1. 将 `config.example.json` 复制为 `config.json`。
2. 在其中填入火山方舟 API Key 和可用模型。
3. 重启 `start.bat`。

图片识别、PDF 简历提取和招聘截图录入需要在模型配置中启用视觉能力。

## 常用操作

### 新增投递

点击右上角“新增投递”。你可以直接手动填写，也可以先打开“招聘信息智能录入”：粘贴岗位文字、拖入截图或使用 `Ctrl + V` 粘贴截图，识别后确认公司、职位和实际投递时间再保存。

“粘贴 JD 解析”适合从招聘页面复制一整段文字。AI 会整理 JD 正文，并在原文包含完整岗位地址时回填 JD 链接。

### 管理面试和准备内容

打开投递详情后可添加面试、动态和复盘。点击面试卡片中的“AI 准备”，系统会先生成计划；确认后可进入任务工作区学习、练习和陪练。

### 录入和导出面经

在“学习”页面选择“录入面经”，可粘贴文字、上传截图或混合录入。面经详情支持编辑题目和答案、重新生成答案、查看答案历史、恢复旧版本，以及导出 Markdown。

同一公司、岗位和轮次可以录入多份他人面经。列表会自动显示 `（1）`、`（2）` 等序号，导出文件也会带相同序号。

### 连接邮箱并生成日程

在右上角“日程”中连接 QQ 或 163 邮箱。请先在邮箱网页设置中开启 IMAP，并生成第三方客户端授权码。

系统以只读方式扫描收件箱，不会发送、删除、移动邮件或改变已读状态。只有你手动识别，或开启自动处理后命中的招聘候选，才会把邮件正文发送给已配置的 AI；附件不会上传。AI 复核通过的明确招聘事项会自动加入日程，之后仍可以修改或取消。

### 分享到飞书

在投递详情点击“分享到飞书”。先在飞书群中创建“自定义机器人”，再在本机 `config.json` 中配置其 Webhook 地址；可参考 `config.example.json`。重启服务后即可发送。飞书收到的是纯文本岗位信息，不含投递进度链接、联系人、联系方式或简历内容。

## 数据与隐私

- 求职记录、截图、复盘、简历和知识库默认保存在本机。
- API Key、邮箱授权码和飞书 Webhook 不会返回到浏览器，也不应提交到 Git。
- 只有点击对应 AI 功能时，所需文字或图片才会发送到你配置的模型服务。
- 建议定期双击 `backup.bat` 备份数据；换电脑时复制数据目录后即可迁移大部分记录，邮箱授权码需要重新填写。
